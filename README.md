# GCGL Scorecard

Migriert von attallah.de-Server (Strato), Ordner `website-2022`.
Live via GitHub Pages: https://dattallah.github.io/gcgl-scorecard/

## Versionierung
Bei jeder Änderung `APP_VERSION` in `index.html` erhöhen und einen Eintrag oben in
`CHANGELOG` ergänzen. Die Historie öffnet sich in der App per Tipp auf die Versionsnummer.
